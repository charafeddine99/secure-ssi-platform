# Architecture Decision Records

Architecture Decision Records (ADRs) capture important choices, alternatives, consequences, and review triggers. Accepted records are not silently rewritten when a decision changes; a new ADR supersedes the old one.

These decisions authorize a synthetic academic prototype only. They do not authorize real identity data, production keys, or external user testing.
